Hubungkan aplikasi Si MasDA

Masukkan URL Web App Google Apps Script yang aktif. Halaman ini tidak dapat menebak URL deployment Anda; gunakan URL produksi yang disalin dari menu Manage deployments.

Buka Apps Script → Deploy → Manage deployments → salin Web app URL yang berakhir dengan /exec. Jangan gunakan URL pengujian yang berakhir dengan /dev.

URL disimpan hanya di penyimpanan lokal browser ini. Jika memakai komputer bersama, jangan aktifkan opsi simpan kata sandi browser.
